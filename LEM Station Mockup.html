The whole program

Every machine runs one of these widgets locally in LabStation. The LEM webserver runs elsewhere as the master view over the entire lab. Nothing talks directly — LabCore is the data bus both ways.

At each machine · N instances
LEM Station widget

Tails that machine's instrument CSV, runs the Data Handler parse pipeline, shows QC per test, writes the master CSV.

parsed rows + status → ← overrides
Data bus
LabCore

All parsed data stored per machine. lem_machine_status out, lem_machine_control back.

status + data → ← control
On the server · 1 instance
LEM master view

The existing web dashboard: lab-wide map, maintenance, checklists — reading everything from LabCore. Can flag any machine SERVICE / DEAD-LINE.

Card anatomy per the reference: bold caps name · battery = remaining QC window (fill drains as QC ages, empty = stale) · ⚡ latest value colored by spec verdict · gray context line · status dot line · instrument photo right · ⚙ parser settings top-right · "ago" stamp bottom-right · caption under the card. One QC section per watched test.
