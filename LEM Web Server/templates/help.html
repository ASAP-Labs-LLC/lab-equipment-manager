Status is a shape and a word

Colour is never the only signal. Each state has its own shape, so it reads the same in light, dark and on a black-and-white printout.

  • A filled dot: fine. "OK to run", "In spec", "Checking in".
  • A ring with a gap: due or quiet. "QC due", "Quiet since 08:48".
  • A triangle: not OK. "Not OK to run", "Out of spec".
  • A hollow ring: nothing to judge by yet. "No verdict yet", "Not read from LabCore yet".

On a tablet or a narrow window

Below 1400 px the sidebar shows icons only. A number on an icon is that page's count, and the strip along the bottom of the page says the status in words. On a phone, the ☰ button opens the full menu. Settings › This browser lets you keep the names showing.

Which version is running

The small text in the bottom-right corner of every page is the release this server is running, and the user menu says it as "LEM {{ app_version() }}". It is the same string /healthz reports. A copy run from a developer's checkout says dev.
